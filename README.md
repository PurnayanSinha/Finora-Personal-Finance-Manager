# Finora – Personal Finance Manager 💰

**Finora** is a modern personal finance management Android application designed to help users manage their money efficiently. It allows users to track income, expenses, credited amounts and savings in one place.

## ✨ Features

- **User Authentication:** Secure registration and login.
- **Income Tracking:** Record and manage different sources of income.
- **Expense Tracking:** Add, edit, and delete daily expenses.
- **Credit Management:** Track money received and credited.
- **Transaction History:** View and manage all financial transactions.
- **Financial Analytics:** Visualize income and expenses through interactive charts.
- **Budget Management:** Monitor spending and manage budgets.
- **Savings Tracking:** Keep track of financial goals.
- **Reports:** View weekly, monthly, and yearly financial summaries.
- **INR Support:** All amounts are displayed in Indian Rupees (₹).
- **Modern UI:** Clean, simple, and user-friendly interface.

## 🛠️ Tech Stack

- Android Application
- Kotlin / Gradle-based project
- Backend and database integration

## 🎯 Purpose

The goal of Finora is to make personal money management simple, organized and accessible by providing users with a centralized platform to track their financial activities.
